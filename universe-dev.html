Universe Dev
E-commerce de niche pour la communauté FiveM / RedM.

Une plateforme sur mesure pensée pour les créateurs et joueurs de serveurs roleplay : catalogue de scripts, espace utilisateur, expérience d'achat fluide et identité visuelle immersive.

  • TypeE-commerce
  • RôleDesign & Dev
  • StackLaravel · React
  • Année2024

Le projet

Une identité forte pour une communauté exigeante.

L'univers FiveM / RedM rassemble une communauté passionnée qui attend des outils à la hauteur de ses serveurs roleplay. L'objectif d'Universe Dev : proposer une boutique claire, rapide et immersive, où chaque script trouve sa place et son public.

Le design joue sur les contrastes profonds, les accents lumineux et une typographie affirmée pour traduire visuellement l'esprit gaming, sans sacrifier la lisibilité ni la conversion.

  • Catalogue orienté conversion

    Navigation claire, filtres pertinents, fiches produits riches.

  • Espace utilisateur sécurisé

    Authentification, historique d'achats, gestion de licences.

  • Architecture modulaire

    Laravel + React pour évoluer sans dette technique.

  • Design immersif

    Identité visuelle pensée pour la communauté gaming RP.
